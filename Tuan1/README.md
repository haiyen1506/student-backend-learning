\# TUẦN 1 - C# CƠ BẢN VÀ GIT



\## Ngày 1 - Làm quen với C#, .NET và Git



\### 1. Nội dung đã thực hiện

\- Tạo project Console App `HelloStudent`.

\- Làm quen với PowerShell và các câu lệnh Git.

\- Khởi tạo Git repository.

\- Tạo file `.gitignore`.

\- Thực hiện `git add`, `git commit`, `git push`.

\- Đưa source code lên GitHub.



\### 2. Bài thực hành

\*\*Tên project:\*\* HelloStudent



\*\*Vị trí:\*\* `console-manager/HelloStudent/`



\*\*Nội dung hiện tại:\*\* Chương trình C# cơ bản in dòng chữ `Hello, World!` ra màn hình.



\### 3. Kết quả

\- Đã tạo commit đầu tiên trên Git.

\- Đã push source code lên GitHub.

\- Chưa ghi nhận kết quả kiểm thử chạy chương trình.



\### 4. Nội dung cần tiếp tục

\- Tìm hiểu kỹ `Program.cs` và `.csproj`.

\- Thực hành `Console.WriteLine()` và `Console.ReadLine()`.

\- Viết chương trình nhập và hiển thị thông tin sinh viên.

\- Kiểm tra và ghi lại kết quả chạy chương trình.
